# Outshell 🐌

**Outshell** is a side-scrolling mobile game featuring physics-based movement, exploration, and level challenges.

## 🎮 Gameplay

The player controls a snail and needs to reach the end of each level while avoiding obstacles and dangerous terrain.

Main actions include:

- Slide to the right
- Enter the shell and roll
- Jump out of the shell
- Avoid falling rocks and high platforms
- Reach the end of each episode

## 🗺 Levels

The game includes multiple handcrafted levels with different terrain layouts, obstacles, and routes.

The first three episodes introduce different combinations of platforming, falling rocks, gravity, and exploration.

## ✨ Highlights

- Simple and intuitive controls
- Physics-based gameplay
- Short level design
- Exploration and strategy
- Mobile-friendly vertical gameplay
